ABOUT THE PROJECT

Machine learning for health awareness.

MediPredict AI is an educational machine learning application that explores relationships between selected symptoms and disease patterns.

It uses a dataset containing 41 disease classes and 131 unique symptoms. Multiple traditional machine learning algorithms were evaluated for classification.

The system is a prototype for academic purposes and is not intended to provide medical diagnoses.
